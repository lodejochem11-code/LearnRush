# LearnRush

LearnRush is een kleurrijke leerwebsite voor pubers met vakken, quizzen, voortgang, badges en een persoonlijk profiel.

## Start lokaal

Open `index.html` in je browser.

## Website

De site bevat:
- een landing page
- een dashboard met XP, streak en badges
- kleurrijke vakkaarten per schoolvak
- een mini-quiz met feedback
- profielpagina met eigen gegevens en avatarkleur
- een werkende inlog-/registratieflow via `localStorage`

## GitHub Pages

Na het activeren van GitHub Pages in de repository-instellingen verschijnt de site op:

https://lodejochem11-code.github.io/LearnRush/

## Opmerking

De profiel- en accountfunctionaliteit werkt lokaal in de browser met browserstorage, zodat iedereen een eigen profiel kan aanmaken zonder backend.
